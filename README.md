# Srowser
Welcome to the Srowser project! Srowser is a lightweight browser that runs on Linux systems. It is a lightweight, open-source browser featuring a wide range of capabilities, such as protection options, built-in translation support, and customizability.

## How to use?
Follow these steps to use Srowser:

* 1: Open your system's console (terminal).
* 2: Enter the provided command (The command is configured for the "Downloads" folder. If your installation directory is different, remember to change the corresponding term. The username specified in the command is set to "user"; if yours is different, remember to update that field):
```bash
sudo apt update
sudo apt install qt6-base-dev qt6-webengine-dev # If available
cd /home/user/Downloads/srowser1/main/build
./Srowser
```
